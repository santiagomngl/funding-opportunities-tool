# External requirements and implemented boundaries

Added for this export; statements are based on the inspected source and local checks.

| Requirement or reference | Where it is used | Included / implication |
| --- | --- | --- |
| npm packages | `package.json`, `package-lock.json` | Manifests and original lockfile included, installed code excluded. All 872 locked `resolved` tarball entries use `registry.npmjs.org`. Installation completed through this environment's package access; a new machine needs reachable package tarballs and compatible native binaries. |
| Linux toolchain | `scripts/install-ci.sh`, `build-verified.sh`, `sites-env.sh` | Scripts included. Require Node, npm, Bash, GNU timeout, flock, curl, sha256sum and Linux `/proc` conventions. Native Windows/macOS execution was not tested. No container or CI infrastructure was added. |
| Optional image-seeded npm cache | `scripts/install-ci.sh`: `SITES_NPM_CACHE_SEED` | Not included. Optional; clean installation used the network path because the available seed did not match this lockfile. |
| Sites identity/metadata | `.openai/hosting.json`, `build/sites-vite-plugin.ts` | Included unchanged. `project_id` identifies the original live Site and is not a credential. Preserve for traceability; this export does not authorize deploying to that Site. |
| Cloudflare Worker runtime | `vite.config.ts`, `worker/index.ts` | Retained. Cloudflare plugin generates Worker configuration with `nodejs_compat`, currently no D1/R2 bindings. Node production startup of the active UI passed locally; no other target deployment was tested. |
| Cloudflare image bindings | `worker/index.ts`: `/_vinext/image` branch | References `env.ASSETS` and `env.IMAGES`. Endpoint and real Cloudflare image services were not tested; current app does not import `next/image` or request this endpoint. Assets use local static URLs. Enabling that branch elsewhere would require corresponding services or adaptation. |
| Database scaffold | `db/index.ts`, `db/schema.ts`, `drizzle.config.ts`, `examples/d1/` | Included but inactive. Main schema and journal contain no tables/migrations. `getDb()` is not called by the application. Notes API under `examples/d1/app/api/` is an example, not an active app route. No database dump or remote data is needed for current behavior. |
| Sites identity and access | `app/chatgpt-auth.ts`, original README | Optional helper reads platform-injected identity headers and links to dispatch-owned sign-in paths; it is not called by this app. Sites access enforcement is outside the source and is not recreated by `npm run start`. No API authentication or SSO backend was implemented or exported. |
| CM2026-01 source PDF | `app/page.tsx`: `cmSourceFilename`, source maps | `CETP_Joint-Call-2026-CallText_FINAL_v20260719.pdf` is unavailable in the source tree. Existing source-label/page maps and Markdown are included. PDF is not fetched at runtime; absence does not prevent startup. Citations were not fact-checked during export. |
| Funding websites and PDF | `data/funding-opportunities.json`, `applicationUrl()` | Existing links to `cetpartnership.eu`, `nwo.nl`, and `rvo.nl` are preserved for navigation, not data ingestion. Link availability/content was not checked and pages were not downloaded. |
| Typography | `app/globals.css`, `public/fonts/` | Montserrat WOFF2 weights and license included. Abadi/Aptos/Segoe UI/Century Gothic are system-font fallbacks; no system-font files were available or added. |
| Icons and UI | `lucide-react`, `components/ui/`, `vendor/` | Icons come from the locked npm dependency, not a missing CDN. Local UI source and vendored stylesheet/license included. Shadcn URL in `components.json` is editor/generator metadata, not an active API. |
| Browser features | `app/page.tsx` | Clipboard, native sharing and fullscreen use browser APIs. Permissions, user gestures and secure contexts apply; no remote service is used. Full browser interaction was not tested for this handoff. |

No missing external Sites helper is needed by the original `install:ci`, `dev`, `build`, or `start` scripts. Historical authoring/publishing helpers and credentials are intentionally not exported. No APIs, ingestion pipelines, schedulers, user accounts, remote persistence or agent backend were found in the active app; documentation or names suggesting future architecture were not treated as implementation.
